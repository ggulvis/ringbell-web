# 링 더 벨 — 웹 배포본

**피의 게임X 5일차 데스매치 "링 더 벨"** 의 빌드 산출물입니다.

▶ **플레이: https://ggulvis.github.io/ringbell-web/**

- 4색(빨강·노랑·초록·파랑) × 1~10, 40장. 4인 2:2 팀전.
- 같은 색 또는 같은 숫자로 높은 조합을 만들고, 상대가 약할 때 종을 친다.
  합이 가장 낮으면 라이프 -1(종을 친 사람이 최하위면 -2).
- 폰에서 열고 **홈 화면에 추가**하면 주소창 없이 실행됩니다.
